# SP ADST Token Presale

A Solana token-presale dashboard for tracking balances, purchase progress, batch schedules, holders, deposits, withdrawals, and transaction history.

![Token purchase progress](./token-presale-preview-2.png)

## Live demo

[web-porto-tokenpresale.vercel.app](https://web-porto-tokenpresale.vercel.app/)

## Stack

React, TypeScript, Vite, Redux Toolkit, React Bootstrap, Axios, and Chart.js.

## Run locally

```bash
pnpm install
pnpm dev
```
